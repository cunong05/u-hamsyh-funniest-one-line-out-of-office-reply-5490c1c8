A single-line out-of-office reply for the make.fun bounty
"Funniest One-Line Out-of-Office Reply" — a fresh spin on the classic
away message: urgent emails get forwarded to Future Me, and he's
ignoring them too.

## Run

```bash
python3 main.py
```

This writes the entry to `/output/entry.txt` — exactly one line,
1–160 characters, UTF-8.
